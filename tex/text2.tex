This is the formula for slope we're using:
$\hat{\beta}_1=\frac{\sum_{i=1}^{n} (x_i-\bar{x})y_i}{\sum_{i=1}^{n} (x_i-\bar{x})^2}$

There are many ways to prove this formula. One is by using the forumla $\hat{\beta} = (X^T X)^{-1}XY$ and taking $\hat{\beta}_1$ from it.
That derivation is a bit tedious though.

\section{Proof}

The regression line must go through $(\bar{x}, \bar{y})$. %why? Do I need to prove this?

Suppose we fix the regression line at $(\bar{x}, \bar{y})$ and vary the slope $\hat{\beta}_1$ and see how ${e_i}^2$ changes.

${e_i}^2=(y_i-\hat{y_i})^2$

Now we consider the derivative of ${e_i}^2$ with respect to $\hat{\beta}_1$. We use the Chain Rule for the derivative of a square.

$\frac{\partial {e_i}^2}{\partial \hat{\beta}_1} = \frac{\partial {e_i}^2}{\partial e_i} \frac{\partial {e_i}}{\partial \hat{\beta}_1}$

$\frac{\partial {e_i}^2}{\partial e_i} = 2e_i = 2(y_i-\hat{y_i})$

$\frac{\partial {e_i}}{\partial \hat{\beta}_1} = \frac{\partial}{\partial \hat{\beta}_1} y_i-\hat{y_i} = \frac{\partial}{\partial \hat{\beta}_1} y_i-(\bar(y) + \hat{\beta}_1(x_i-\bar{x})) = \frac{\partial}{\partial \hat{\beta}_1} (- \hat{\beta}_1(x_i-\bar{x})) = -(x_i-\bar{x})$

Therefore,

$\frac{\partial {e_i}^2}{\partial \hat{\beta}_1} = 2(y_i-\hat{y_i}) * -(x_i-\bar{x}) = -2(x_i-\bar{x})(y_i-\hat{y_i})$

At the least-squares estimate, the sum of all the partials of ${e_i}^2$ with respect to $\hat{\beta}_1$ must be zero.

$\sum_{i=1}^{n}\frac{\partial {e_i}^2}{\partial \hat{\beta}_1}=0$

$\sum_{i=1}^{n}-2(x_i-\bar{x})(y_i-\hat{y_i})=0$

$\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\hat{y_i})=0$

So we want to find the slope such that $\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\hat{y_i})=0$.

Let us define $E_1 = \sum_{i=1}^{n}(x_i-\bar{x})(y_i-\hat{y_i})$. This is not standard notation, it is just something that I made up.

I claim that $E_1$ varies linearly with $\hat{\beta}_1$. Again, this is assuming we keep the regression line fixed going through $(\bar{x}, \bar{y})$.

$\frac{\partial E_1}{\partial \hat{\beta}_1} = \frac{\partial}{\partial \hat{\beta}_1} \sum_{i=1}^{n}(x_i-\bar{x})(y_i-\hat{y_i})$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = \frac{\partial}{\partial \hat{\beta}_1} \sum_{i=1}^{n}(x_i-\bar{x})y_i - \frac{\partial}{\partial \hat{\beta}_1} \sum_{i=1}^{n}(x_i-\bar{x})\hat{y_i}$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - \frac{\partial}{\partial \hat{\beta}_1} \sum_{i=1}^{n}(x_i-\bar{x})\hat{y_i}$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - \sum_{i=1}^{n}(x_i-\bar{x}) \frac{\partial}{\partial \hat{\beta}_1} \hat{y_i}$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - \sum_{i=1}^{n}(x_i-\bar{x}) \frac{\partial}{\partial \hat{\beta}_1} (\bar{y} + (x_i-\bar{x}) \hat{\beta}_1)$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - \sum_{i=1}^{n}(x_i-\bar{x}) (x_i-\bar{x})$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - \sum_{i=1}^{n}(x_i-\bar{x})^2$

$\frac{\partial E_1}{\partial \hat{\beta}_1} = - n $Var$(x)$

This is a constant and doesn't depend on $\hat{\beta}_1$.
